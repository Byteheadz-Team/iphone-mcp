# services/ — Domain services

All services extend `Module` (from `@lib/utils`) and receive dependencies via constructor injection.

## mirroring/

`MirroringService` wraps `MirroringClient` (from `lib/mirroring/`) with `Module` lifecycle and coordinate mapping. On `start()`, it requests Accessibility and Screen Recording permissions (triggering macOS system prompts if not granted), resolves the host app name, caches permission warnings in the `permissionWarnings` property (`{ accessibility: string | null, screenRecording: string | null }`), detects the macOS "Natural scrolling" preference via `MirroringClient.isNaturalScrolling()`, launches iPhone Mirroring, and caches window info. Permission warnings include the host app name and are surfaced to the MCP client through tool responses.

Key responsibility: **coordinate mapping**. Screenshots are captured at the configured resolution (`config.mirroring.screenshotScale`, default 1) with a grid overlay that adds padding on all four sides. `takeScreenshot()` also passes `config.mirroring.compressPngPalette` and `config.mirroring.pngCompressionLevel` through to `captureWindow()` for PNG output compression. Grid layout is computed dynamically via `computeGridLayout()` using the image's short side and `config.mirroring.overlayGridDivisions`. The AI sends coordinates in the padded screenshot pixel space; the service subtracts the computed padding offset and divides by the scale factor to convert to macOS screen points: `screen_x = window.x + (pixel_x - padding) / scale`. Coordinates are validated as finite numbers via zod before being passed to CGEvent. `getGridLayout()` returns the current computed layout; it throws if called before `start()` (i.e. before window dimensions are available).

Also provides clipboard via `pbpaste`/`pbcopy` (Universal Clipboard) and button simulation via keyboard shortcuts (⌘1 home, ⌘2 app switcher, ⌘3 spotlight).

The MCP tool layer calls `MirroringService` directly for screenshots, tap, swipe, scroll, type, and button press — there are no intermediate wrapper services. `tap()` accepts an optional `numTaps` parameter which is passed through to `MirroringClient.postClick()`. `scroll()` accepts `direction` (`'up' | 'down' | 'left' | 'right'`, default `'down'`) and `distance` (positive number, defaults to half the screen dimension in the scroll direction — half height for up/down, half width for left/right), converts screenshot-pixel coordinates to screen coordinates (same as `tap()`/`swipe()`), maps direction + distance to `deltaX`/`deltaY`, negates deltas when natural scrolling is ON, and delegates to `MirroringClient.postScroll()`. Both `postScroll()` and `postDrag()` use `config.mirroring.motionStepIntervalMs` (default 50ms) for animation step timing. The `ScrollDirection` type is exported from the service module. `swipe()` divides the duration by `config.mirroring.swipeSpeed` (default 2) before delegating to `MirroringClient.postDrag()`. `getWindowInfo()` returns cached window info (throws if called before `start()`).
